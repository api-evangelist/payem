# Payem

> PayEm is a global spend management and procurement platform that automates the
> request-to-reconciliation process for finance, procurement, HR and operations teams.
> Founded 2019; San Francisco and Tel Aviv. SOC 1 and SOC 2 Type II attested (EY).

IMPORTANT FOR AGENTS: PayEm publishes no public product API. There is no developer
portal, no API reference, no SDK, no CLI, no webhook catalog, no MCP server and no agent
card. Integration with PayEm is via its own pre-built ERP/HRIS connectors, arranged
through a sales conversation. The only machine-readable contract reachable from payem.co
is an AI-discovery content API operated by LightSite.ai on PayEm's behalf; it serves
marketing and knowledge content and cannot perform any action in the PayEm product.

## Machine-readable contracts

- [OpenAPI 3.1 (AI Discovery)](https://www.payem.co/.well-known/openapi.json): 308 to
  api.llm-discovery-api.com; 10 read-only GET operations returning schema.org JSON-LD.
  Anonymous. Requires ?domain=payem.co.
- [AI plugin manifest](https://www.payem.co/.well-known/ai-plugin.json): 308 to the same
  vendor host.
- [Skills manifest](https://api.llm-discovery-api.com/functions/v1/llm-discovery/public/.well-known/skills.json?domain=payem.co):
  four capability hints with openapi_ref pointers and published rate limits.
- [AI catalog](https://api.llm-discovery-api.com/functions/v1/llm-discovery/public/.well-known/ai-catalog.json?domain=payem.co):
  AIR 1.0 catalog listing the contract, the skills manifest and the search endpoint.
- Rate limits: 60/min on /business, /products and /categories; 30/min on /search. No
  rate-limit headers are returned.

## Security and compliance

- [Security & compliance](https://www.payem.co/legal/security-and-compliance): MFA, SAML
  SSO, AES-256 at rest, in-field encryption, least privilege with audit logging,
  continuous automated penetration testing, GDPR and CCPA.
- [SOC 2 Type II](https://www.payem.co/legal/soc-2) — annually audited by EY.
- [SOC 1 Type II](https://www.payem.co/legal/soc-1-type-ii-compliant)
- [Trust center](https://security.payem.co/) — SafeBase portal; returns a bot challenge to
  automated clients.
- No security.txt, no published vulnerability disclosure policy, no bug bounty.
